# Redwood Workbench Next Design Fidelity Assessment

## Reference evidence

The approved Sites source was recovered from the live reference as HTML, `styles.css`, and `app.js` and retained locally as temporary design evidence. The reference establishes a dark engagement spine, condition-first overview, Work/Review/Decision lenses, horizontal workflow progress, material-number context, and contextual evidence thread.

## Adapted overview

`/next/index.html?run=<canonical-run-id>` now opens a canonical run in **Engagement** overview mode. The adapted screen uses:

- condition-first gate/finding orientation;
- Work / Review / Decision lenses using only canonical run state;
- workflow progress that navigates to all seven canonical phases;
- material reconciliation figures that retain control definition, value, status, and evidence-drawer action;
- attention items from canonical gates and findings;
- run ID, inventory count, and G7 state.

## Limitations

This environment does not provide browser screenshot capture, so desktop/mobile side-by-side screenshot evidence remains a manual acceptance item. Static route, JavaScript syntax, build, and canonical run HTTP verification passed. No default interface switch is authorized.
