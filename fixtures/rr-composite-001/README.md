# RR-COMPOSITE-001

Synthetic authored composite-signal evidence fixture. It records two distinct observed indicators without selecting, weighting, blending, or adding them into an economic conclusion.

## Intake boundary

Only `claims.csv` and `payments.csv` are intake sources. `Truth_Contract.json` is post-run comparison evidence and must not be ingested.

## Evidence-only boundary

The component signals remain separately identifiable. Redwood must not double count them, derive a composite recovery rate, create an automatic QoR adjustment, or imply professional approval.
