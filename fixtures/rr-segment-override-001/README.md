# RR-SEGMENT-OVERRIDE-001

Synthetic authored segment-override evidence fixture. It demonstrates different observed segment outcomes while preserving the absence of authority to override a segment assumption or normalize revenue.

## Intake boundary

Only `claims.csv` and `payments.csv` are intake sources. `Truth_Contract.json` is post-run comparison evidence and must not be ingested.

## Evidence-only boundary

Service lines are observed dimensions, not approved override keys. A future segment override requires an approved method/profile rule, explicit eligibility and rationale, evidence lineage, run binding, and professional authorization. This fixture creates no override and automatic normalization is zero.
